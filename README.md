# rosio-site

The source of https://sa1ntsinner.github.io/rosio/, the site of [rosio](https://github.com/sa1ntsinner/rosio).

`node build.mjs` writes `index.html` from `index.src.html` and the recorded command output in `output/`. The `site` workflow of the rosio repository deploys it: run it by hand after a push, or wait for its daily run.
